# xena-project

Xena Project API client for Python.

## Installation

```bash
pip install xena-project
```

## Usage

```python
from xena_project import ProjectApi

# Create API client
api = ProjectApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
