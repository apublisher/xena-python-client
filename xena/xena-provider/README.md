# xena-provider

Xena Provider API client for Python.

## Installation

```bash
pip install xena-provider
```

## Usage

```python
from xena_provider import ProviderApi

# Create API client
api = ProviderApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
