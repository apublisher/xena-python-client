# xena-core

Xena Core API client for Python.

## Installation

```bash
pip install xena-core
```

## Usage

```python
from xena_core import CoreApi

# Create API client
api = CoreApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
