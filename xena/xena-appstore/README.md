# xena-appstore

Xena Appstore API client for Python.

## Installation

```bash
pip install xena-appstore
```

## Usage

```python
from xena_appstore import AppstoreApi

# Create API client
api = AppstoreApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
