# xena-finance

Xena Finance API client for Python.

## Installation

```bash
pip install xena-finance
```

## Usage

```python
from xena_finance import FinanceApi

# Create API client
api = FinanceApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
