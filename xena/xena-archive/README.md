# xena-archive

Xena Archive API client for Python.

## Installation

```bash
pip install xena-archive
```

## Usage

```python
from xena_archive import ArchiveApi

# Create API client
api = ArchiveApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
