# xena-price

Xena Price API client for Python.

## Installation

```bash
pip install xena-price
```

## Usage

```python
from xena_price import PriceApi

# Create API client
api = PriceApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
