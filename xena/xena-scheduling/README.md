# xena-scheduling

Xena Scheduling API client for Python.

## Installation

```bash
pip install xena-scheduling
```

## Usage

```python
from xena_scheduling import SchedulingApi

# Create API client
api = SchedulingApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
