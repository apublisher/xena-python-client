# xena-partner

Xena Partner API client for Python.

## Installation

```bash
pip install xena-partner
```

## Usage

```python
from xena_partner import PartnerApi

# Create API client
api = PartnerApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
