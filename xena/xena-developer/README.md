# xena-developer

Xena Developer API client for Python.

## Installation

```bash
pip install xena-developer
```

## Usage

```python
from xena_developer import DeveloperApi

# Create API client
api = DeveloperApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
