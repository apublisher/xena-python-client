# xena-accountant

Xena Accountant API client for Python.

## Installation

```bash
pip install xena-accountant
```

## Usage

```python
from xena_accountant import AccountantApi

# Create API client
api = AccountantApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
