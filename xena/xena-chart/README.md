# xena-chart

Xena Chart API client for Python.

## Installation

```bash
pip install xena-chart
```

## Usage

```python
from xena_chart import ChartApi

# Create API client
api = ChartApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
