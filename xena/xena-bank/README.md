# xena-bank

Xena Bank API client for Python.

## Installation

```bash
pip install xena-bank
```

## Usage

```python
from xena_bank import BankApi

# Create API client
api = BankApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
