# xena-subscription

Xena Subscription API client for Python.

## Installation

```bash
pip install xena-subscription
```

## Usage

```python
from xena_subscription import SubscriptionApi

# Create API client
api = SubscriptionApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
