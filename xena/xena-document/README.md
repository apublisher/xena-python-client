# xena-document

Xena Document API client for Python.

## Installation

```bash
pip install xena-document
```

## Usage

```python
from xena_document import DocumentApi

# Create API client
api = DocumentApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
