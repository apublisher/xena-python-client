# xena-article

Xena Article API client for Python.

## Installation

```bash
pip install xena-article
```

## Usage

```python
from xena_article import ArticleApi

# Create API client
api = ArticleApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
