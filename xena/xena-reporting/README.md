# xena-reporting

Xena Reporting API client for Python.

## Installation

```bash
pip install xena-reporting
```

## Usage

```python
from xena_reporting import ReportingApi

# Create API client
api = ReportingApi(base_url="https://my.xena.biz")

# Use the API methods
# ... (see Xena API documentation)
```

## Requirements

- Python 3.8+
- requests>=2.25.0
